熱中性子管理棟（校正）— データまとめ

2026-08-22 午後に、黒鉛パイルでの校正・Gain 試験・PE 効果確認を行った。地下施設キャンペーン（等価コンクリート図 11/12）とは別セッションである。

MCA はピークを積算するモードであるため、dead time では較正点を捨てない。計数率は net / LIVE_TIME。計測効率は ε = εS / S_iso（無次元）。

較正の定義（d1 / D1 共通）

メーカー感度は等方熱場の全計数（cps/nv = εS_total）。現場の主窓は壁効果 191–764 keV。

εS_total = メーカー cps/nv
S_iso    = π r (L+r)/2　（L = He-3 が入っている長さ）
ε_mfr    = εS_total / S_iso　（メーカー公称の計測効率）
f_wall   = d1 パイル 30&80 cm の R_wall / R_total
εS_wall  = εS_total × f_wall
φ        = R_wall / εS_wall

パイル点束 φ は米内ほか, 保健物理 37(2) 118–127 (2002)：Q = 2.26×106 n/s、φ/Q = 9.44×10−6 @30 cm、R_half = 95 cm。φ(30) = 21.33、φ(80) = 10.88 n/cm²/s。

パイル R/φ は点束×長い円筒のためメーカー公称と一致しなくてよい（照合）。絶対 φ の主結果はメーカー × f_wall。

実績

εS_meas = R / φ、ε_meas = εS_meas / S_iso。メーカーは全計数。D1 は ch0 除外の ch1+。

採用する実測: d1 は 30&80 cm の平均（距離比が理論と整合）。D1 は Gain=750・coarse=100（変更後）の ch1+。D1 @30 cm はパイルアップで不採用。80 cm（gain 前）は参考。
