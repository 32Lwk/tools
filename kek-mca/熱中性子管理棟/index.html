熱中性子管理棟（校正）— データまとめ

2026-08-22 午後に、黒鉛パイルでの校正・Gain 試験・PE 効果確認を行った。地下施設キャンペーン（等価コンクリート図 11/12）とは別セッションである。

MCA はピークを積算するモードであるため、dead time では較正点を捨てない。計数率は net / LIVE_TIME（追加の 1/(1−DT) はしない）。ch0 オーバーフローは dead time とは別指標で、大径管では ch1+ をメーカー比較に使う。

較正の定義（d1 / D1 共通）

メーカー感度は等方熱場の全計数（cps/nv = εS_total）。現場の主窓は壁効果 191–764 keV。

εS_total = メーカー cps/nv
S_iso    = π r (L+r)/2
ε_mfr    = εS_total / S_iso
f_wall   = d1 パイル 30&80 cm の R_wall / R_total
εS_wall  = εS_total × f_wall
φ        = R_wall / εS_wall
  • d1 … S_iso は実測外形：高さ L = 39.53 cm、幅（直径）= 5.08 cm。
  • D1 … S_iso は He-3 内半径 ×（全長 − 信管）= 4.80 cm × 56 cm。
  • d2 / D2 … PE 付きのため裸管メーカーは使わない。現場の wall CPS 比で D1 から転送。

パイル点束 φ は米内ほか, 保健物理 37(2) 118–127 (2002)：Q = 2.26×106 n/s、φ/Q = 9.44×10−6 @30 cm、R_half = 95 cm。φ(30) = 21.33、φ(80) = 10.88 n/cm²/s。

パイル R/φ は点束×長い円筒のため、等方校正のメーカー値とは一致しなくてよい。照合用。主結果はメーカー × f_wall。

d1 の 30/80 比は観測 R30/R80 = 2.04、理論 φ30/φ80 = 1.96 で整合。εS がメーカーの約 68% なのは、パイルが等方場ではなく点状熱束だからである。

D1 @30 cm は ch1+ でもメーカーの 1.9 倍で、ch0≈33% と高計数のパイルアップが残る。照合は 80 cm 規模（gain 確定後は公称の 95–99%）を使う。主結果の εS_total(D1) はメーカー 450 のまま。

管理棟2階の D1/d1 CPS 比は宇宙線スペクトルなので、熱中性子 εS には使わない（参考のみ）。

解析窓は 2 系統

³He(n,p)³H の Q 値は 764 keV。壁効果によりエネルギー付与はおよそ 191–764 keV に連続分布する。ピーク近傍だけを切ると壁効果成分を落とす。公式 φ は wall 窓。

系統 窓の定義 背景 d1 ε×S [cm²] D1 ε×S [cm²]
peak ROI（参考） シリアル別固定窓（例: 2162 は ch 350–408） 両側帯 70.1（=123 × f_peak） 256（=450 × f_peak）
wall 191–764 keV（主窓） ピーク=764 keV 線形校正 → 191–764 keV 右側帯（必要なら平坦部） 112.3（=123 × 0.913） 410.9（=450 × 0.913）

f_wall = 0.913（d1 パイル 30 cm で 0.896、80 cm で 0.930）。Gain を変えた D1 では固定 peak ROI がピークを外すことがある。wall 窓と全計数（ch1+）は使える。
