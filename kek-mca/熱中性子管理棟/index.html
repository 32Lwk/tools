熱中性子管理棟（校正）— データまとめ

2026-08-22 午後に実施した黒鉛パイル校正・Gain 試験・PE 効果確認の結果です。地下施設キャンペーン（等価コンクリート図 11/12）とは別セッションです。

要点
  • 絶対効率が取れたのは d1（小径・SN 2162） のみ：ε×Stotal ≈ 89.4 cm²、ε×SROI ≈ 50.2 cm²
  • 絶対フラックス φ = CPSROI,net / (ε×SROI) は d1 のみ。現場の絶対 φ も d1 基準
  • D1（30/80 cm）は計数率が高く 飽和 → 絶対較正不可
  • D2/d2 @ 約 400 cm は 黒鉛なし・PE 効果確認 → 熱中性子 φ(d) 公式は使わない

1. フラックスの求め方

  1. 校正場で ROI NET 計数率 CPS を測る（側帯引き後）
  2. 文献（米内ほか, 保健物理 37(2) 118–127, 2002）の熱中性子束 φ を用いる
    Q = 2.26×106 n/s、φ/Q = 9.44×10−6 n/(s·cm²·Q)（基準距離）、Rhalf = 95 cm
  3. 効率×面積 ε×S = CPS校正 / φ校正（単位 cm²）
  4. 現場では φ = CPS現場 / (ε×S)（単位 n/cm²/s）

同一検出器の地点比較なら相対 φ ≈ 相対 CPS。D1/D2/d2 は絶対 ε×S 未確定のため相対比較のみ。
