なぜ d1 だけ検出効率が出ているか

絶対効率 ε×S = CPS / φ既知 には、「文献の熱中性子束 φ が使える条件」と「検出器が線形応答していること」の両方が必要です。

  • d1（30・80 cm） … 黒鉛パイル表面から水平距離で測定。文献の熱 φ(d) 公式が使え、計数率も非飽和。絶対較正 OK
  • D1（30・80 cm） … 同じ幾何だが大径のため CPS が非常に高く（〜10²–10³ /s）、デッドタイム・ch0 溢れで飽和。CPS が φ に比例しないので ε×S を出せない。不可
  • D2 / d2（≈400 cm） … 黒鉛なし・Am-Be+PE の見通し距離。熱中性子場の公式が前提と違うため、φ既知 を置けない（PE 効果の相対比較用）。不可

D 系の再較正予定がないため、現場の絶対フラックスは d1 のみ。他検出器は地点間の相対 CPS（= 相対 φ）で比較します。

フラックスの求め方

  1. 校正場で ROI NET 計数率 CPS を測る（側帯引き後）
  2. 文献の熱中性子束 φ を用いる（米内ほか, 保健物理 37(2) 118–127, 2002） Q = 2.26×106 n/s　·　φ/Q = 9.44×10−6 n/(s·cm²·Q)　·　Rhalf = 95 cm
  3. 効率×面積を求める ε×S = CPS校正 / φ校正　[cm²]
  4. 現場フラックスへ換算 φ = CPS現場 / (ε×S)　[n/cm²/s]

同一検出器の地点比較なら相対 φ ≈ 相対 CPS。
