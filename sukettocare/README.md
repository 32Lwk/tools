# 助っ人ケア 発表スライド

- `index.html` をブラウザ（Chrome 推奨）で開く。→ / Space / クリックで次へ、← で戻る。
- **発表者モード（2画面）**: 会場の画面を拡張ディスプレイでつなぐ → `index.html` の「発表者モードで始める」→ 開いた発表者画面は手元に、スライドのウィンドウはプロジェクターへドラッグ →「ここで全画面にして始める」。`presenter.html` から始めて「スライドを開く」でも同じ。
- 発表者画面: 原稿（いま読む行の色が変わる）・経過時間・予定とのずれ・4:00 までの残り・次のページ。スライドの操作はこの画面からもできる。
- スライドで `P` を押しても発表者画面が開く。
- `F` 全画面、`S` タイマー開始（最初の「次へ」でも始まる）、`T` タイマーを 0 に、`R` 映像を最初から、`B` 黒画面、`H` 操作の説明。
- `qa.html` 想定問答、`print.html` 印刷用の原稿、`原稿.md` 原稿のテキスト。
- 原稿とタイミングは `script.json` → `data.js`。映像は `media/`（動画の元素材から、字幕と音声なしで書き出したもの）。
